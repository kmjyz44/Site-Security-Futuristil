# SecureHome Chicago - Сайт з Адмін-Панеллю

Повнофункціональний сайт для компанії з систем безпеки та ремонтних послуг з потужною адмін-панеллю.

## 🚀 Особливості

### Публічний Сайт
- ✨ Футуристичний дизайн з neon-ефектами
- 📱 Повністю адаптивний (responsive)
- 🎨 Темна тема з градієнтами
- 📧 Форма зворотного зв'язку з email-відправкою
- 🎯 Динамічний контент з можливістю керування
- 📸 Галерея послуг з зображеннями
- 🔍 SEO-оптимізація (robots.txt, sitemap.xml)

### Адмін-Панель
- 🔐 Захищена авторизація (JWT)
- 📝 Керування контентом сайту
- 🖼️ Керування розділами/послугами
- 📨 Перегляд повідомлень від клієнтів
- ✉️ Налаштування Email (Resend/SendGrid)
- 🤖 Підготовка до інтеграції чатбота
- 👁️ Приховування/показ розділів

## 🛠 Технології

### Backend
- **FastAPI** - швидкий Python веб-фреймворк
- **MongoDB** - NoSQL база даних
- **JWT** - автентифікація
- **bcrypt** - хешування паролів
- **httpx** - асинхронні HTTP запити

### Frontend
- **React 18** - UI бібліотека
- **React Router** - маршрутизація
- **Tailwind CSS** - стилізація
- **Lucide Icons** - іконки
- **Axios** - HTTP клієнт

### Email Провайдери
- **Resend** - сучасний email сервіс
- **SendGrid** - надійний email сервіс

## 🔧 Налаштування

### Початкові Дані для Входу
**Логін:** `admin`  
**Пароль:** `admin123`

⚠️ **Важливо:** Змініть пароль після першого входу!

### Налаштування Email

1. Перейдіть в Адмін-Панель → Email
2. Оберіть провайдера (Resend або SendGrid)
3. Створіть акаунт на сайті провайдера:
   - **Resend:** https://resend.com
   - **SendGrid:** https://sendgrid.com
4. Отримайте API ключ
5. Вкажіть:
   - API Key
   - Email відправника (From)
   - Email отримувача (To)
6. Збережіть налаштування

## 📝 Керування Контентом

### Редагування Тексту
1. Адмін → Контент
2. Змініть:
   - Заголовки Hero секції
   - Текст "Про Нас"
   - Контактну інформацію
3. Натисніть "Зберегти"

### Керування Послугами
1. Адмін → Розділи
2. Можна:
   - Додати нову послугу
   - Редагувати існуючу
   - Приховати/показати
   - Видалити
   - Змінити порядок

## 🤖 Чатбот (Підготовка)

В адмін-панелі підготовлено місце для майбутньої інтеграції чатбота:

- Увімкнення/вимкнення
- Вибір кольору віджета
- Налаштування привітання
- Позиціонування (праворуч/ліворуч внизу)

## 📧 Повідомлення

Всі повідомлення з форми зворотного зв'язку:
- Зберігаються в базі даних
- Відправляються на email (якщо налаштовано)
- Доступні для перегляду в адмінці
- Можна позначити як прочитані
